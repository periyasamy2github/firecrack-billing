# Mobile-App Responsive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the SparkBill SPA feel like a native mobile app on phones (bottom tab navigation, card lists, full-screen dialogs, checkout-style billing) so the deployed URL can be shipped as an Android APK, while leaving the desktop UI pixel-identical.

**Architecture:** All mobile behavior lives behind a single 768px breakpoint. CSS media queries in the existing co-located `.module.css` files handle layout; a tiny `useIsMobile` hook handles the few places the DOM must differ (full-screen dialogs). Desktop and mobile shells both render inside `AppLayout` and CSS shows exactly one. Tables that matter on a phone (Bills, Products, Customers) get a parallel card-list component; every other table scrolls horizontally inside its existing `TableCard`. The APK is a Trusted Web Activity generated by PWABuilder from the already-working PWA — zero app code.

**Tech Stack:** React 19 + TypeScript, MUI 6, CSS Modules, react-router-dom 7, vite-plugin-pwa (already configured), PWABuilder (packaging only).

**Spec:** No separate spec file — the design was agreed in chat on 2026-09-21. Summary: (1) mobile shell = dark top bar + bottom tab bar (Dashboard / New Bill / Bills / Products / More-sheet), (2) hide all keyboard-shortcut UI on touch devices, (3) dialogs full-screen on mobile, (4) New Bill single-column with sticky total/save bar, (5) Bills/Products/Customers become tappable cards on mobile, (6) everything else stacks or scrolls, (7) APK via PWABuilder + `assetlinks.json` upload.

## Global Constraints

- Breakpoint is **768px everywhere**: CSS `@media (max-width: 768px)`, JS `useIsMobile()`. Never introduce a second breakpoint value.
- **Desktop must not change.** Every mobile rule sits inside a media query or an `isMobile` branch. No edits to existing desktop declarations unless the task explicitly says so.
- Arrow-function components only (`const Foo = () => …`), never `function Foo()`.
- Static styles go in the co-located `.module.css` file; `sx` only for genuinely runtime-dynamic values. Match existing file conventions (import order, `Mono`, `StatusPill`, `styles` import last).
- No new dependencies.
- No test suite exists. Verification per task = `npx tsc -b` (fast) plus the listed manual/Playwright check. Do not claim browser behavior verified without running the app.
- **Never `git commit`** — the user commits manually. Each phase ends with a checkpoint where the user reviews the diff (agreed: preview per phase, not per edit).
- Touch detection for hiding keyboard UI is `@media (hover: none) and (pointer: coarse)` — independent of the 768px width query.

```tsx
// src/layouts/MobileBottomNav.tsx
import { useState } from 'react'
import { useLocation, useNavigate } from 'react-router-dom'
import { Divider, Drawer, List, ListItemButton, ListItemIcon, ListItemText, Typography } from '@mui/material'
import MoreHorizRoundedIcon from '@mui/icons-material/MoreHorizRounded'
import LogoutRoundedIcon from '@mui/icons-material/LogoutRounded'
import DownloadOutlinedIcon from '@mui/icons-material/DownloadOutlined'
import { PRIMARY_NAV, MASTER_NAV, type NavItem } from './navItems'
import { useSession } from '../hooks/useSession'
import { usePwaInstall } from '../hooks/usePwaInstall'
import styles from '../css/layouts/MobileNav.module.css'

const TAB_PATHS = ['/', '/bills/new', '/bills', '/products']
const ALL_NAV = [...PRIMARY_NAV, ...MASTER_NAV]
const TABS = TAB_PATHS.map((path) => ALL_NAV.find((item) => item.to === path)!)

export const MobileBottomNav = () => {
  const navigate = useNavigate()
  const { pathname } = useLocation()
  const { isSuperAdmin, currentUser, signOut } = useSession()
  const { canInstall, install } = usePwaInstall()
  const [moreOpen, setMoreOpen] = useState(false)

  const moreItems = ALL_NAV.filter((item) => !TAB_PATHS.includes(item.to) && (!item.superAdminOnly || isSuperAdmin))
  const isActive = (to: string) => (to === '/' || to === '/bills' ? pathname === to : pathname.startsWith(to))
  const moreActive = moreItems.some((item) => isActive(item.to))

  const go = (to: string) => {
    setMoreOpen(false)
    navigate(to)
  }

  const tabButton = (item: NavItem) => (
    <button key={item.to} type="button" className={isActive(item.to) ? `${styles.tab} ${styles.tabActive}` : styles.tab} onClick={() => go(item.to)}>
      <item.icon className={styles.tabIcon} />
      <span className={styles.tabLabel}>{item.label}</span>
    </button>
  )

  return (
    <>
      <nav className={`${styles.bottomNav} mobile-only no-print`}>
        {TABS.map(tabButton)}
        <button type="button" className={moreActive ? `${styles.tab} ${styles.tabActive}` : styles.tab} onClick={() => setMoreOpen(true)}>
          <MoreHorizRoundedIcon className={styles.tabIcon} />
          <span className={styles.tabLabel}>More</span>
        </button>
      </nav>

      <Drawer anchor="bottom" open={moreOpen} onClose={() => setMoreOpen(false)} PaperProps={{ className: styles.moreSheet }}>
        <div className={styles.moreHandle} />
        <List>
          {moreItems.map((item) => (
            <ListItemButton key={item.to} selected={isActive(item.to)} onClick={() => go(item.to)}>
              <ListItemIcon><item.icon /></ListItemIcon>
              <ListItemText primary={item.label} />
            </ListItemButton>
          ))}
          {canInstall && (
            <ListItemButton onClick={() => { setMoreOpen(false); void install() }}>
              <ListItemIcon><DownloadOutlinedIcon /></ListItemIcon>
              <ListItemText primary="Install app" />
            </ListItemButton>
          )}
          <Divider />
          <ListItemButton onClick={() => { setMoreOpen(false); signOut() }}>
            <ListItemIcon><LogoutRoundedIcon /></ListItemIcon>
            <ListItemText primary="Sign out" secondary={currentUser?.name} />
          </ListItemButton>
        </List>
        <Typography className={styles.moreVersion}>SparkBill</Typography>
      </Drawer>
    </>
  )
}
```

Check `useSession` for the exact `signOut` call shape (AppLayout uses `onSignOut={() => { signOut(); }}` — there may be a confirmation toast added in commit 8aa0f77; mirror whatever `LoggedProfile` does so mobile sign-out behaves identically).
